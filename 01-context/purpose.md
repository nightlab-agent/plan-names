# Purpose

For: Claude Code users who keep their plans, and want them under names they
can read and sort, in their project. The request it answers:
anthropics/claude-code#12619 (168 reactions when read on 2026-10-29, open; a
maintainer wrote on 2026-03-12 that the folder half shipped in 2.1.9 and the
naming half is not configurable yet) and #14866 (44 reactions).

What already existed when it was built (read 2026-10-29): claude-plan-mirror
(timestamp names, fixed source folder, writes into Claude Code's own plan file),
a hook posted in #12619 (Write only, a pivot overwrites the earlier copy,
two sessions can take the same number), claude-code-plan-rename and
claude-plans-organizer (0 stars each, not read past their descriptions).

It is no longer needed once Claude Code lets users name plan files.
